# Sistema Link

Página estática simples (HTML/CSS/JS) com uma tela de verificação/interstitial.

## Estrutura

- `index.html` — marcação da página
- `style.css` — estilos
- `script.js` — lógica da verificação/redirecionamento

## Como rodar localmente

Basta abrir o `index.html` no navegador, ou servir a pasta com um servidor estático, por exemplo:

```bash
npx serve .
```
